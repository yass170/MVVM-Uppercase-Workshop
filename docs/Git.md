# Git — suggestions de commits

Vous pouvez suivre une démarche de commits incrémentaux (exemple) :

1. `chore: init solution + core project`
2. `feat: add console view (v1) + validation`
3. `docs: add UML v1 (classes + sequence)`
4. `feat: add WPF project (v2) with MVVM binding`
5. `docs: update UML v2 + architecture explanation`
6. `docs: add recipe test sheet`

Le dépôt ici est livré sans historique Git, mais avec une structure et un `.gitignore` prêts à l'emploi.
